Privacy Policy

Last updated: August 2, 2026

1. Scope

Shiwei Oura Codex is a private, non-commercial integration intended solely for use by its owner. This policy explains how information may be processed when the integration is used.

2. Website data

This informational website does not intentionally use advertising trackers, analytics scripts, account registration forms, or payment systems.

3. Oura data

After explicit authorization by the account owner, the integration may access selected health and wellness data associated with that owner's Oura account. Depending on the permissions granted, this may include sleep, readiness, activity, workout, heart-rate, blood-oxygen, and related account information.

4. Purpose of processing

Data is processed only to respond to specific personal analysis requests made by the account owner. It is not used for advertising, profiling other people, resale, or unrelated commercial purposes.

5. AI and MCP processing

Any processing involving an AI service must use an Oura-authorized MCP workflow and must comply with the current Oura API and MCP Agreement. Oura data must not be used to train, fine-tune, evaluate, or improve an AI model.

6. Credentials and security

Authentication credentials, client secrets, access tokens, and refresh tokens must not be published on this website or stored in its public GitHub repository. Where applicable, credentials are stored locally using access restrictions appropriate to the owner's device.

7. Retention

Oura data should not be retained longer than is strictly necessary for the owner's requested analysis. Data and authorization credentials will be deleted or invalidated when access is revoked or the integration is discontinued, subject to applicable legal requirements.

8. Disclosure

Oura data is not sold. It may only be transmitted to service providers that are strictly necessary to complete the owner's requested processing and whose applicable terms are compatible with Oura's requirements.

9. Medical information

Information generated through this integration is provided for personal informational purposes. It is not a medical diagnosis and is not a substitute for advice from a qualified healthcare professional.
